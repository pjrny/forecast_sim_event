# v1.5 — Patron Journey theme, shared nav, lineup pay & date effects

Requested by Oscar (2026-11-17). Live copy: https://events-patronjourney.message-0ad.workers.dev/forecaster/

## Changes
- **Theme**: `css/app.css` variables switched to the Patron Journey email/tools palette (cream #F8F4EC, gold #B8932E,
  ink #2B2620, muted #6B6257, Georgia headings, Helvetica body). Hard-coded dark colors replaced; poster.js canvas colors unchanged.
- **Shared nav**: `<script src="https://events-patronjourney.message-0ad.workers.dev/pj-nav.js" data-active="forecaster">`
  injects the same sticky bar as every other tool (source: Events-Patron-Journey-Organizer `src/nav.ts`). The app header
  sits below it via `--pj-nav-h`; the stepper uses `--ff-header-h`.
- **Lineup, artist pay & date effects** (Step 1, `js/lineup_talent.js`): paste the lineup (`Artist | fee` optional) and a total
  artist budget ("Use sim Talent line" copies C48), optional private historic shows (shared `/pj-history.js` widget).
  Calls the Worker's `POST /api/talent/draw` (talent-draw.v2) with city/state, start/end date, genre, ticket price,
  Limit Registrations cap. Shows lineup-driven turnout (date-adjusted), per-artist suggested fee + market range + flags.
- **Date effects**: `GET /api/date-effects` for start–end (country from Timezone). Shown whenever a start date is set.
- **Attendance N is never changed silently**: "Use X as Attendance N" (lineup) or "Apply ×m to Attendance N" (date only,
  re-applies against the remembered base N, not compounding).
- `app.js`: 2-line hook after `BudgetEngine.compute` (`window.__ffLastBudget`, `ff:recalc` event).

Model docs: Worker repo `docs/TALENT.md` (v2 + pay), `docs/DATE_EFFECTS.md`, `docs/HISTORY.md`.
